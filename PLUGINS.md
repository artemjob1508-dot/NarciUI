# Плагины для NarciUI

Плагин — отдельный аддон, который дополняет NarciUI через его открытый интерфейс `NarciUI_API`. Он может:

- добавить свою страницу в настройки аддона;
- добавить стили неймплейтов и сумок, текстуры полос, шрифты;
- добавить готовые образы и блоки показателей;
- ставить свои фреймы в общий режим перемещения и в раскладки;
- подписываться на события аддона;
- добавлять варианты оформления любого элемента, свои окна, разделы настроек, кнопки микро-меню, теги, условия и строки подсказок (API версии 5).

Готовый пример лежит в `Plugins/NarcissusSirus_Example`. Скопируйте эту папку в `Interface\AddOns`, перезапустите клиент, и плагин появится в настройках, в разделе «Плагины».

## Подключение

В `.toc` плагина укажите зависимость, чтобы он загружался после аддона:

```
## Interface: 30300
## Title: Мой плагин
## Dependencies: NarciUI
```

В начале файла возьмите API и проверьте, что он есть:

```lua
local API = NarciUI_API
if not API then return end
```

## Когда что вызывать

1. **Файл плагина загружается после NarciUI, до входа в игру.** В этот момент регистрируйте сам плагин и все расширения: стили, текстуры, шрифты, образы, блоки показателей, переводы. Блоки показателей принимаются только до входа: панель показателей строится при входе.
2. **После входа в игру аддон вызывает `onLoad` каждого включённого плагина.** К этому моменту интерфейс аддона построен и тема применена. Здесь создавайте свои фреймы и подписывайтесь на события.
3. **Ошибки в плагине не ломают аддон.** Все вызовы плагина идут через `pcall`: ошибка пишется в чат с именем плагина и видна на странице «Плагины».

Используйте `API:After(секунды, функция)`, а не `C_Timer.After`: на Sirus `C_Timer.After` падает, если в одном кадре запланировано несколько таймеров.

## Регистрация

```lua
API:RegisterPlugin("ИмяАддонаПлагина", {
    title = "Название в настройках",
    version = "1.0",
    author = "Автор",
    description = "Одна-две фразы о плагине",
    apiVersion = 1,
    defaults = { ... },
    onLoad = function(api, db, plugin) end,
    settings = function(page, ui, db, api) end,
})
```

- `name` — уникальное имя, лучше имя папки аддона.
- `apiVersion` — версия API, на которую рассчитан плагин. Если она новее `API.VERSION`, плагин не запускается и помечается «нужна новая версия NarciUI».
- `defaults` — значения по умолчанию для настроек плагина. Заполняются рекурсивно, уже сохранённые значения не трогаются.
- `db` — таблица настроек плагина в текущем профиле аддона: `NarcissusSirusDB.profiles[профиль].plugins[имя]`. Она меняется вместе с профилем и попадает в его экспорт.
- Каждый плагин автоматически получает выключатель на странице «Части аддона». Выключенный плагин не запускается после перезагрузки.

## Страница настроек

Если задан `settings`, плагин получает свою страницу в разделе «Плагины». Её содержимое строится функциями из `ui`, которые выглядят и работают как остальные настройки аддона:

| Функция | Что делает |
|---|---|
| `ui.Section(page, текст)` | заголовок раздела |
| `ui.Label(page, текст)` | подпись над следующим элементом |
| `ui.Note(page, текст)` | серый поясняющий текст с переносом |
| `ui.Check(page, текст, значение, function(value) end)` | галка |
| `ui.Slider(page, текст, мин, макс, шаг, значение, function(value) end, суффикс)` | ползунок |
| `ui.Picker(page, { {key=, label=}, ... }, текущий, function(key) end)` | выбор из вариантов, возвращает виджет с `:Refresh(key)` |
| `ui.Buttons(page, { {label=, width=, action=}, ... })` | ряд кнопок |
| `ui.Color(page, текст, function() return r, g, b end, function(r, g, b) end)` | образец цвета с палитрой |

Элементы встают сверху вниз в порядке вызова. Страница строится один раз, при первом открытии настроек. `API:OpenSettings(имя)` открывает страницу плагина.

## Расширения

Регистрируйте их при загрузке файла. Все функции возвращают `true`, если запись принята. Ключ, который уже занят, не принимается.

### Стиль неймплейтов

`API:AddNameplateStyle(строка)` — строка в формате таблицы `STYLES` из `Modules/HUD/Nameplates.lua`.

- **Обязательные поля:**
  - `key`, `name`;
  - `width`, `height`;
  - `texture`: `flat`, `shaded`, `smooth` или `gradient`;
  - `border`: `thin`, `thick`, `pixel`, `classic`, `accent`, `glow` или `none`;
  - `nameAt`: `above`, `below` или `inside`;
  - `nameAlign`;
  - `hpAt`: `none`, `header`, `right`, `center`, `both` или `outside`;
  - `level`: `none`, `header`, `right` или `box`.
- **Необязательные:** `sheen`, `sheenStrong`, `shadow`, `ticks`, `namePlate`, `nameColor` (`health`, `grey`), `nameSize`, `bgColor`, `bgAlpha`, `accentTop`, `threatGlow`.

Если обязательное поле пропущено, оно берётся из стиля «Обсидиан».

### Стиль сумок

`API:AddBagStyle(строка)` — формат таблицы `STYLES` из `Modules/HUD/Bags.lua`.

- `frame`: `flat`, `dialog`, `gold`, `tooltip` или `none`.
- `cell`: `edges`, `stock`, `glow`, `underline` или `fill`.
- Необязательные:
  - `pad`, `bg`, `border`, `shadow`, `accentLines`;
  - `art` и `artColor` — путь к текстуре фона и её цвет;
  - `title`: `gold`, `white` или `brown`;
  - `text = "dark"`;
  - `cellBg`, `cellBorder`, `thickness`, `emptyAlpha`.

### Текстура полос и шрифт

```lua
API:AddBarTexture("ключ", "Название", "Interface\\...")
API:AddFont("ключ", "Название", "Interface\\AddOns\\МойПлагин\\font.ttf")
```

Текстура появляется в выборе на страницах «Вида элементов», шрифт — там же и в «Шрифте аддона».

### Готовый образ

```lua
API:AddLook({
    key = "ключ", name = "Название",
    styles = { frame = ..., buttons = ..., micro = ..., cast = ..., tooltip = ..., chat = ..., minimap = ...,
               raid = ..., auras = ..., data = ..., cooldown = ..., threat = ..., plates = ..., bags = ... },
    look = { texture = "ключ текстуры", outline = "default|none|outline|thick|mono" },
})
```

Значение каждого стиля должно быть ключом, который принимает соответствующий модуль, в том числе добавленным плагином. Иначе модуль молча вернётся к своему стилю по умолчанию.

### Блок показателей

```lua
API:AddDataText({ key = "ключ", label = "Подпись", value = function() return "текст" end })
```

`value` вызывается на каждом обновлении панели показателей и должна быстро вернуть строку. Блок можно включить на странице «Показатели».

## Свои текстуры (API версии 3)

Плагин может положить свои картинки в свою папку и добавить их как новые варианты оформления. Каждый вариант появляется в выборе на нужной странице настроек рядом со встроенными и сохраняется в профиле, как любой другой. Плагин, который пользуется этими функциями, указывает `apiVersion = 3`.

Требования к файлам:
- **Формат.** TGA или BLP, стороны — степени двойки (64, 128, 256, 512).
- **Цвет.** Рисуйте белым на прозрачном: цвет аддон накладывает сам (качество предмета, цвет темы, цвет орнамента).
- **Путь.** Полный, вида `Interface\\AddOns\\МойПлагин\\Media\\имя` (расширение не пишется).
- **Перезапуск.** Новый файл клиент видит только после полного перезапуска игры.

Регистрировать нужно при загрузке файла плагина, до входа в игру, как стили неймплейтов. Каждая функция возвращает `true`, если вариант добавлен, и `false`, если ключ занят встроенным или другим плагином либо данные неполные.

### Форма слотов

```lua
API:AddSlotShape("myshape", {
    label = "Моя форма",
    fill  = "Interface\\AddOns\\МойПлагин\\Media\\ShapeFill",
    ring  = "Interface\\AddOns\\МойПлагин\\Media\\ShapeRing",
    inner = "Interface\\AddOns\\МойПлагин\\Media\\ShapeInner",
    size  = 58,
    icon  = 40,
})
```

- `fill` — сплошная фигура, она заливается цветом ячейки.
- `ring` — контур, он красится в цвет качества предмета или в цвет темы.
- Необязательные:
  - `inner` — внутренняя тень, тонируется цветом темы; она же служит подсветкой при наведении;
  - `ringSize` — размер контура, если он отличается от `size`;
  - `iconY` — сдвиг иконки по вертикали.

`size` — размер фигуры в точках при слоте 48×48; `icon` — диаметр круглой иконки внутри. Сама кнопка слота остаётся квадратной кнопкой клиента, меняется только рисунок. Вариант появляется в «Окно персонажа → Слоты и модель → Форма слотов».

### Подсветка за моделью и круг под ногами

```lua
API:AddBacklight("aurora", "Сияние", {
    path = "Interface\\AddOns\\МойПлагин\\Media\\Aurora",
    width = 700, height = 700, alpha = 0.3, spin = false,
})
API:AddFloor("sigil", "Печать", "Interface\\AddOns\\МойПлагин\\Media\\Sigil", { alpha = 0.5, spin = true })
```

- **Подсветка** рисуется за моделью в режиме сложения цветов, тонируется выбранным цветом подсветки и умножается на её силу. `spin = true` медленно вращает картинку, поэтому её лучше делать квадратной.
- **Круг под ногами** — вид сверху: аддон сплющивает картинку до трети высоты и кладёт под ноги, поэтому рисуйте его круглым, как на полу.

Варианты появляются в «Слоты и модель» → «Вид подсветки» и «Круг под ногами».

### Оформление окон

```lua
API:AddWindowPattern("stars", "Звёзды", "Interface\\AddOns\\МойПлагин\\Media\\PatternStars")
API:AddCornerStyle("thorns", "Шипы", "Interface\\AddOns\\МойПлагин\\Media\\CornerThorns")
API:AddDividerStyle("vine", "Лоза", "Interface\\AddOns\\МойПлагин\\Media\\DividerVine")
```

- **Узор** повторяется плиткой по всему окну, поэтому его края должны стыковаться. Удобный размер — 64×64.
- **Угол** рисуется для левого верхнего угла, 64×64; остальные три угла аддон получает отражением.
- **Разделитель** — горизонтальная полоса 512×16 с центром посередине; концы лучше растворять в прозрачность.

Варианты появляются в «Стиль → Детали стиля» и применяются после перезагрузки интерфейса.

### Иконки микро-меню

```lua
API:AddMicroIcons("myicons", "Мои иконки", {
    Character = "Interface\\AddOns\\МойПлагин\\Media\\Char",
    Spellbook = "Interface\\AddOns\\МойПлагин\\Media\\Book",
    Talent = "Interface\\AddOns\\МойПлагин\\Media\\Tree",
})
```

Ключи — имена кнопок клиента без `MicroButton`:
- `Character`, `Spellbook`, `Talent`, `Achievement`, `QuestLog`, `Socials`, `Guild`;
- `LFD`, `Collections`, `EncounterJournal`, `Store`, `MainMenu`.

Можно указывать и полные имена кнопок. Кнопки, которых нет в наборе, получают полноценные иконки аддона. Иконки рисуются в своих цветах, без тонировки, и становятся серыми, когда кнопка недоступна. Набор появляется в «Панели команд → Микро-меню → Иконки микро-меню».

## Полная кастомизация (API версии 4)

С этими функциями плагин может переделать аддон под себя: заменить его картинки, добавить свои цвета, вкладки и настройки, подменить поведение модулей. Плагин, который ими пользуется, указывает `apiVersion = 4`. Все регистрации делаются при загрузке файла плагина, до входа в игру.

### Замена любой текстуры аддона

```lua
API:ReplaceTexture("HexRing", "Interface\\AddOns\\МойПлагин\\Media\\MyHexRing")
API:ReplaceTexture("Glow", "Interface\\AddOns\\МойПлагин\\Media\\SoftGlow")
```

- **Имя** — имя файла из папки `NarciUI\Media` без расширения: `HexRing`, `Glow`, `DecorCorner`, `BannerTalents`, `ToolStats`, `FullCharacter`, `PatternDots` и любой другой.
- **Как применяется.** Аддон берёт замену везде, где рисует эту текстуру. Новая картинка должна повторять размер и раскладку оригинала: например, у `BannerTalents` сцена лежит в левой трети.
- **Цвет.** Белые части тонируются так же, как у оригинала.

### Цвета темы и тона фона

```lua
API:AddAccent("teal", "Бирюза", 0.10, 0.70, 0.70)
API:AddBackgroundTone("plum", "Слива", 0.05, 0.02, 0.05)
```

- **Цвет темы** появляется среди образцов на странице «Оформление». Приглушённый и яркий варианты аддон выводит из основного сам.
- **Тон фона** появляется в «Тема окон → Тон фона».

Оба применяются после перезагрузки интерфейса, как встроенные.

### Своя вкладка в окне персонажа

```lua
API:AddTab({
    key = "notes",
    label = "Заметки",
    title = "Мои заметки",
    icon = "Interface\\AddOns\\МойПлагин\\Media\\NotesIcon",
    banner = "Interface\\AddOns\\МойПлагин\\Media\\NotesBanner",
    badge = function() return 3, "ЗАПИСИ" end,
    build = function(content, frame)
        local text = content:CreateFontString(nil, "OVERLAY")
        text:SetFont(API:Font(nil, API:FontSize(12), ""))
        text:SetPoint("TOPLEFT")
        frame.text = text
    end,
    update = function(content, frame)
        frame.text:SetText("Обновлено: " .. date("%H:%M"))
    end,
}, "МойПлагин")
```

- **Вид.** Аддон сам строит вкладку в общем стиле: окно 440×340 справа, рамка, тень, заголовок, разделитель, шапка с картинкой в стилизованном виде. Кнопка с иконкой добавляется на панель инструментов перед «Настройками».
- **Поведение.** Открыть вкладку можно только одну за раз, как встроенные.
- `build(content, frame)` вызывается один раз, при первом открытии. `content` — пустая область под заголовком (420×272), в ней плагин рисует своё.
- `update(content, frame)` вызывается при каждом открытии.
- Необязательные поля: `title`, `icon`, `banner` (картинка шапки 1024×128, сцена в левой трети) и `badge` (значок в шапке, функция возвращает число и подпись).
- **Иконка** белая, 64×64: она красится в цвет темы, когда вкладка открыта.

### Свои настройки на любой странице

```lua
API:AddSettings("chat", function(page, UI)
    UI.Section(page, "Мой плагин")
    UI.Check(page, "Подсвечивать моё имя", db.highlight, function(value) db.highlight = value end)
end, "МойПлагин")
```

- Первый аргумент — ключ страницы: `style`, `styledetails`, `look`, `theme`, `character`, `charslots`, `chat`, `bars`, `micro`, `nameplates`, `bags`, `tooltip`, `minimap` и другие. Ключи перечислены в `CATEGORIES` в `UI/Settings.lua`.
- Элементы добавляются в конец страницы, через те же помощники, что у страницы плагина. Поиск по настройкам находит и их.

### Подмена и дополнение поведения модулей

```lua
API:Override("TooltipSkin", "Paint", function(original, self, tooltip, ...)
    original(self, tooltip, ...)
    tooltip:SetBackdropBorderColor(1, 0.8, 0.2)
end, "МойПлагин")

API:HookAny("NarciUI", "UpdateSlots", function(self)
end, "МойПлагин")

local panel = API:GetModule("StatsPanel")
```

- `Override(модуль, метод, функция, плагин)` ставит функцию плагина вместо метода. Функция получает исходный метод первым аргументом и сама решает, вызывать ли его.
  - Если функция плагина падает с ошибкой, ошибка показывается с именем плагина, а аддон вызывает исходный метод, так что окно не ломается.
  - Если плагин выключен, работает исходный метод.
- `HookAny(модуль, метод, функция, плагин)` вызывает функцию после метода, ничего не подменяя.
- `GetModule(имя)` возвращает таблицу модуля: `NarciUI`, `StatsPanel`, `ChatSkin`, `ActionBars`, `Bags`, `Nameplates` и любой другой из `NS`. Закрыты `Plugins`, `PluginAPI`, `db` и таблицы переводов.

Это прямой доступ к внутренностям аддона, и обещания стабильности на него нет: имена методов и их аргументы могут меняться между версиями. Для того, что входит в обещание, есть `API:Hook` с постоянными именами элементов. Два ограничения клиента:
- **Защищённые функции.** Не подменяйте методы, которые работают с защищёнными кнопками: слоты снаряжения, панели команд, рамки юнитов. Подмена из кода плагина делает вызов «заражённым», и клиент заблокирует действие в бою.
- **Сохранённые ссылки.** Подмена действует только на вызовы через таблицу модуля. Если модуль сохранил функцию в локальную переменную, подмена её не затронет.

## Всё остальное (API версии 5)

Версия 5 закрывает места, куда раньше можно было попасть только через `GetModule`. Плагин, который пользуется этими функциями, указывает `apiVersion = 5`.

**Когда регистрировать.** Как и раньше, при загрузке файла плагина, до входа в игру. Исключение — `AddTooltipLines`, его можно вызывать когда угодно.

**Что возвращают.** Каждая функция возвращает `true`, если вариант принят. Если ключ уже занят или данных не хватает, она возвращает `false`.

**Где появляется вариант.** В выборе на странице настроек этого элемента, рядом со встроенными. Образец при наведении показывает и его.

### Замена шрифтов и полос аддона

`API:ReplaceTexture` теперь заменяет и всё, что раньше было прописано путём:
- **Текстуры полос** «Вида элементов»: `BarSoft`, `BarGloss`, `BarBevel`, `BarMatte`, `BarGlass`, `BarMetal`, `BarNeon`, `BarStripes`, `BarHatch`. Полоса неймплейтов `BarSoft` тоже.
- **Встроенные шрифты.** Имя пишется с расширением:
  - `PTSansNarrow.ttf`
  - `Magistral.ttf`
  - `Expressway.ttf` (он же шрифт подписи)
  - `ContinuumMedium.ttf`
  - `ActionMan.ttf`
  - `Homespun.ttf`
  - `DieDieDie.ttf`

```lua
API:ReplaceTexture("Expressway.ttf", "Interface\\AddOns\\МойПлагин\\Fonts\\My.ttf")
```

### Рамки мелких элементов

```lua
API:AddBoxStyle("ember", "Угли", {
    base = "flat",
    ground = { 0.08, 0.03, 0.02, 0.9 },
    edge = { 1, 0.45, 0.1, 1 },
    glow = { 1, 0.4, 0.1, 0.5 },
    border = { file = "Interface\\AddOns\\МойПлагин\\Media\\EmberBorder", size = 12, color = { 1, 0.6, 0.3, 1 } },
    art = { file = "Interface\\AddOns\\МойПлагин\\Media\\EmberArt", alpha = 0.4, blend = "ADD" },
    ring = { 1, 0.45, 0.1, 1 },
    paint = function(frame, box, opts) end,
})
```

**Где действует.** Это общая рамка `SkinBox`. Её используют:
- ресурсы класса;
- полоса опыта и кнопка выхода из транспорта;
- кнопка и панель утилит рейда;
- кнопка мессенджера;
- трекер заданий и координаты;
- стили окон, диалога и AFK-экрана.

**Как строится стиль.**
- `base` — встроенный стиль, который рисуется первым: `flat`, `pixel`, `glass`, `neon`, `soft`, `classic`, `gold` или `none`.
- Поля, перекрывающие основу (все необязательны):
  - `ground` — фон;
  - `edge` — тонкие края;
  - `glow` — свечение;
  - `border` — рамка из файла в формате рамки подсказок;
  - `art` — картинка на всю рамку;
  - `ring` — цвет кольца для круглых элементов.
- `paint(frame, box, opts)` вызывается последним.

### Значок поиска группы

```lua
API:AddQueueIcon("lotus", "Лотос", {
    file = "Interface\\AddOns\\МойПлагин\\Media\\QueueLotus",
    found = "Interface\\AddOns\\МойПлагин\\Media\\QueueLotusFound",
    full = true,
    glow = { 1, 0.5, 0.8 },
    foundGlow = { 0.45, 1, 0.55 },
})
```

**Файлы.** Каждый файл — 16 кадров сеткой 4×4: 256×256 с кадрами по 64 точки или 512×512 с кадрами по 128.
- `file` — анимация поиска;
- `found` — анимация «группа найдена»; без неё в этот момент крутится та же анимация.

**Цвет.**
- Без `full` картинка белая и красится выбранным цветом значка. Когда группа найдена, она красится в цвет «группа найдена».
- С `full = true` картинка рисуется в своих цветах. `glow` и `foundGlow` — цвет свечения вокруг неё в обычном состоянии и когда группа найдена.

### Трекер заданий и координаты

```lua
API:AddTrackerStyle("ember", "Угли", { box = "ember", fade = false, paint = function(panel, db) end })
API:AddCoordStyle("ember", "Угли", { box = "ember", plate = false, outline = true, text = { 1, 0.7, 0.4 }, paint = function(pill) end })
```

- `box` — ключ рамки, встроенной или добавленной через `AddBoxStyle`.
- `fade` у трекера включает тающий чёрный фон.
- `plate` у координат включает плашку `Pill`, `outline` — обводку текста, `text` — цвет текста.

### Окна, диалог, AFK-экран и мессенджер

```lua
API:AddSceneArt("forest", "Interface\\AddOns\\МойПлагин\\Media\\Forest", 2, "bottom")
API:AddWindowStyle("forest", "Лес", { scene = "forest", box = "flat", tint = { 0.4, 0.8, 0.5 } })
API:AddDialogueStyle("forest", "Лес", { base = "night", card = { scene = "forest", box = "flat" } })
API:AddAFKStyle("forest", "Лес", { scene = "forest" })
API:AddMessengerStyle("forest", "Лес", { base = "glass", art = "Interface\\AddOns\\МойПлагин\\Media\\Forest" })
```

**Картинка сцены.** `AddSceneArt(ключ, путь, соотношение сторон, якорь)` добавляет картинку, которую стили берут по ключу `scene`. Якорь:
- `bottom` или `top`;
- или число от 0 до 1 — вертикальный центр.

**Поля стилей.** Они те же, что у встроенных:
- окна — `Movers.WINDOW_STYLES`;
- диалог — `Dialogue.STYLES`;
- AFK-экран — `AFKScreen.PANEL_STYLES`;
- мессенджер — `M.STYLES` в `MessengerWindow.lua`.

**Поле `base`.** Копирует недостающие поля из встроенного стиля. Удобнее всего взять похожий и изменить пару полей.

### Рамки юнитов и рейда

```lua
API:AddUnitFrameStyle("ember", "Угли", { base = "classic", paint = function(frame, db) end })
API:AddRaidStyle("ember", "Угли", {
    base = "blocks",
    sizes = { width = 96, height = 40, powerSize = 3 },
    paint = function(button, db) end,
})
```

**Как устроен стиль.**
- **Раскладка.** Её рисует встроенный стиль `base`.
- **`paint`.** Вызывается после каждой перерисовки: у рамки юнита после раскладки, у рейд-кнопки после раскладки и рамки. В ней можно перекрасить или добавить свои текстуры.
- **`sizes`.** Размеры, которые ставит выбор стиля рейда.

**Защищённые кнопки.** Это защищённые кнопки. В `paint` можно менять только внешний вид: текстуры, цвета, шрифты. Не трогайте атрибуты, размер, показ и скрытие самих кнопок.

### Новый элемент «Вида элементов»

```lua
API:AddLookElement({
    key = "mymeter", name = "Мой счётчик", bars = true,
    colors = { "bar", "bg", "border", "text" },
    refresh = function() MyMeter:Repaint() end,
})
```

**Страница.** Элемент получает свою страницу в «Вид элементов».

**Как подключить.**
- Шрифты задавайте через `API:Font("mymeter", размер, флаги)`.
- Полосы — через `Look:SetBar(полоса, "mymeter")`, его даёт `API:GetModule("Look")`.
- Цвета берите из `Look:Color("mymeter", "bar")`.

Тогда текстура полос обновляется сама. `refresh` перекрашивает остальное, в том числе шрифты, заданные через `API:Font`.

### Своё окно в «Окнах аддона»

```lua
API:AddWindow({ name = "MyPlugin_Window", label = "Мой журнал", module = "PluginTab_notes",
    tabs = { { key = 1, label = "Первая" }, { key = 2, label = "Вторая" } } })
```

**Что получает окно.** Как у окон аддона:
- масштаб;
- запоминание позиции;
- свой стиль;
- раскладку, чтобы не открывалось поверх других;
- закрытие в бою.

**Поля.**
- `name` — глобальное имя фрейма, он может появиться позже.
- `module` и `tabs` нужны только для стартовой вкладки: аддон пишет выбранный ключ в `NS[module].tab`.

### Раздел настроек

```lua
API:AddSettingsCategory({ key = "mymeter", title = "Мой счётчик", group = "Информация на экране",
    build = function(page, UI) UI.Section(page, "Мой счётчик") end }, "МойПлагин")
API:AddSettingsCategory({ key = "mymeter_more", title = "Дополнительно", parent = "ext_mymeter",
    build = function(page, UI) end }, "МойПлагин")
```

**Куда встаёт раздел.**
- **По группе.** Раздел встаёт в конец группы `group`: «Начало», «Внешний вид», «Окно персонажа», «Окна игры», «Рамки и панели», «Информация на экране», «Чат и общение», «Помощники», «Профили» или своей (старые имена «Окна», «Интерфейс в игре» и «Управление» тоже принимаются). Без группы — в «Дополнения».
- **Подстраницей.** `parent` делает раздел подстраницей существующего: ключ из `CATEGORIES` или `ext_<ключ>` другого раздела плагина.

**Поиск.** Работает и здесь.

### Кнопка в микро-меню

```lua
API:AddMicroButton({
    key = "notes", label = "Заметки", tooltip = "Открыть заметки",
    icon = "Interface\\AddOns\\МойПлагин\\Media\\MicroNotes",
    full = "Interface\\AddOns\\МойПлагин\\Media\\FullNotes",
    onClick = function(button, mouse) end,
}, "МойПлагин")
```

**Иконки.**
- `icon` — белая, красится, как у встроенных.
- `full` — цветная, для наборов «полноценные», «неон» и других.

**Где появляется.** Кнопка встаёт в конец микро-меню и в список «Какие кнопки показывать».

**Ограничение.** Это обычная кнопка, не защищённая. Поэтому `onClick` не может вызывать защищённые функции клиента.

### Теги рамок юнитов

```lua
API:AddTag("mana:short", function(unit) return math.floor(UnitPower(unit, 0) / 1000) .. "k" end, "МойПлагин")
```

**Имя тега.** Латиница, цифры, `:` и `-`. Тег сразу работает в шаблонах `[mana:short]` и появляется в списке тегов на странице вида рамок.

**Ошибки.** Если функция падает, тег пишет пустую строку.

### Условие правил неймплейтов

```lua
API:AddPlateCondition({
    key = "markedskull", label = "Метка",
    options = { { key = "skull", label = "череп" }, { key = "none", label = "без метки" } },
    test = function(unit, value)
        local index = GetRaidTargetIndex(unit)
        if value == "skull" then return index == 8 end
        return index == nil
    end,
}, "МойПлагин")
```

**Где появляется.** Условие получает свой выбор в редакторе правила. Вариант «неважно» добавляется сам.

**Без `options`.** Выбор из «выполнено» и «не выполнено», `value` приходит как `yes` или `no`.

**Выключенный плагин.** Его условие считается выполненным.

### Строки в подсказках часов и золота

```lua
API:AddTooltipLines("clock", function(tooltip)
    tooltip:AddLine(" ")
    tooltip:AddDoubleLine("Мировой босс", "через 2 ч", 1, 1, 1, 0.7, 0.7, 0.7)
end, "МойПлагин")
```

**Куда попадают строки.**
- `clock` — в подсказку часов на миникарте и блока «Время» в показателях.
- `money` — в подсказку блока «Золото».

Строки добавляются в конец подсказки.

## Общие инструменты

| Вызов | Что даёт |
|---|---|
| `API:Styling()` | цвета и помощники оформления аддона: `ACCENT`, `BORDER`, `TEXT_*`, `Bg()`, `CreateEdges`, `CreateShadow`, `CreateSoftShadow`, `FadeIn` и другие из `UI/Styling.lua` |
| `API:Widgets()` | готовые элементы: `CreateThemedButton`, `CreateThemedCheckbox`, `CreateThemedEditBox`, `CreateCloseButton`, `ShowConfirm` |
| `API:Font(элемент, размер, флаги)` | шрифт с учётом «Вида элементов»; без элемента — шрифт аддона. Используйте как `fs:SetFont(API:Font(nil, API:FontSize(11), "OUTLINE"))` |
| `API:FontSize(n)` | размер с учётом общего масштаба шрифта |
| `API:L(текст)` | перевод строки |
| `API:AddTranslations("enUS", { ["русский"] = "english" })` | переводы плагина. Исходный язык — русский, как во всём аддоне |
| `API:RegisterMover(фрейм, подпись, function(point, relativePoint, x, y) end)` | фрейм появляется в режиме перемещения и в раскладках под роль; функция сохраняет позицию |
| `API:After(сек, функция)` | безопасный таймер |
| `API:Print(текст)` | сообщение в чат с меткой аддона |
| `API:GetDB(имя)`, `API:GetPlugin(имя)`, `API:IsPluginEnabled(имя)` | данные плагинов |
| `API.VERSION`, `API.ADDON_VERSION` | версия API и версия аддона |

## Готовые интерфейсы (API версии 2)

Эти функции нужны плагинам, которые настраивают весь интерфейс под себя, как `Plugins/NarcissusSirus_Twilight`. Плагин, который ими пользуется, указывает `apiVersion = 2`.

| Вызов | Что делает |
|---|---|
| `API:GetSetting("путь")` | читает настройку текущего профиля аддона, путь через точку: `"actionBars.bars.bar1.size"` |
| `API:SetSetting("путь", значение)` | записывает настройку. Таблицы `plugins` и `pluginsEnabled` закрыты. Модули читают большинство настроек при загрузке, поэтому после серии изменений вызывайте `API:Reload()` |
| `API:ApplySettings({ ["путь"] = значение, ... })` | то же для многих настроек сразу |
| `API:Elements()` | список элементов режима перемещения: `id`, `label`, `frame`, `name` |
| `API:PlaceElement(имя, точка, точка_экрана, x, y)` | ставит элемент на место и сохраняет позицию так же, как перетаскивание. Имя - `id`, имя фрейма или подпись. Вне боя |
| `API:Hook(элемент, функция, "ИмяПлагина")` | вызывает функцию после того, как модуль нарисовал элемент; аргументы - те же, что у функции модуля (обычно сам фрейм). Список элементов - `API.HOOKS` |
| `API:RefreshLook(элемент)` | перерисовать элемент «Вида элементов» без перезагрузки; без аргумента - все |
| `API:Reload()` | перезагрузить интерфейс. На Sirus работает только из клика игрока (кнопка, подтверждение в окне); из таймера или события клиент её блокирует |

Элементы `API:Hook`: `actionbutton`, `actionedges`, `actionbar`, `unitframe`, `unitbars`, `raidbutton`, `raidborder`, `raidhealth`, `aura`, `auratint`, `auraduration`, `aurasapplied`, `chatpanel`, `chattab`, `chattabs`, `chatapplied`, `minimap`, `minimapapplied`, `datatexts`, `castbar`, `nameplate`, `tooltip`, а с версии 5 ещё `tracker`, `queueicon`, `coords`, `raidrole`, `raidrank`, `window`, `dialogue`, `afk`, `messenger`, `bagwindow`, `threat`, `cooldowns`, `xpbar`, `classpower`, `look`. Перехват ставится, когда плагин его вызывает, поэтому элементы, нарисованные раньше, обновятся при следующей перерисовке; `API:RefreshLook()` её вызывает.

## События

```lua
API:On("СОБЫТИЕ", function(event, ...) end, "ИмяПлагина")
API:Off("СОБЫТИЕ", "ИмяПлагина")
```

Третий аргумент связывает подписку с плагином: если плагин выключен или не запустился, его обработчики не вызываются.

| Событие | Когда |
|---|---|
| `READY` | все плагины запущены |
| `CHARACTER_SHOWN` / `CHARACTER_HIDDEN` | открыто или закрыто окно персонажа аддона |
| `LAYOUT_APPLIED` | применена раскладка под роль, аргумент — её ключ |
| `LOOK_APPLIED` | выбран готовый образ, аргумент — его ключ |
| `SETTINGS_SHOWN` | открыто окно настроек |

## Правила

- Пользуйтесь только `NarciUI_API`. Внутренняя таблица аддона может меняться от версии к версии, а API — нет: изменения, ломающие плагины, поднимают `API.VERSION`.
- Давайте своим фреймам имена с префиксом своего плагина.
- Не используйте `C_Timer.After`, берите `API:After`.
- Проверяйте вызовы клиентского API по исходникам клиента Sirus: это изменённый клиент 3.3.5a.
